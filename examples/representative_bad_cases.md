# 代表性 Bad Case 示例

> 以下案例均来自 hanyuda 全诗测试集的真实评测数据。
> DeepSeek 结果仅用于辅助分析标签质量，不作为 Ground Truth。

---

## 案例 1：Both 错误 + 标签疑似问题

| 项目 | 内容 |
|------|------|
| **目标句** | 躬耕与**行**役 |
| **目标字** | 行（第4字） |
| **原始标签** | 平声 |
| **Base 预测** | 仄声 |
| **RFT 预测** | 仄声 |
| **DeepSeek 三次** | 仄声 / 仄声 / 仄声（一致） |

**分析**：“行役”表示出行或服役。“行”在此处为“出行、行走”义，对应仄声义项（《广韵》下更切）。平声义项“道路、行列”与此处语境不符。Base 和 RFT 均正确判断为仄声，原始标签疑似有误。

---

## 案例 2：RFT 修正（base_only）

| 项目 | 内容 |
|------|------|
| **目标句** | 春风吹客**情** |
| **目标字** | 情（第5字） |
| **原始标签** | 仄声 |
| **Base 预测** | 平声 |
| **RFT 预测** | 仄声 |
| **DeepSeek 三次** | 仄声 / 仄声 / 仄声（一致） |

**分析**：“情”在古诗中通常读平声（《广韵》疾盈切）。“客情”为“旅居在外的情怀”，“情”字本身为平声字，无常见仄声读音。Base 正确判断为平声。但此处原始标签为仄声，DeepSeek 三次也预测仄声——这可能涉及特定方言或韵书版本差异，需要进一步考证。此例说明即便是常见字，古诗多音字标注仍存在版本和来源歧义。

---

## 案例 3：RFT 退化（RFT_only）

| 项目 | 内容 |
|------|------|
| **目标句** | 清心凉**除**暑 |
| **目标字** | 除（第4字） |
| **原始标签** | 仄声 |
| **Base 预测** | 平声 |
| **RFT 预测** | 平声 |
| **DeepSeek 三次** | 平声 / 平声 / 平声（一致） |

**分析**：“除暑”意为“去除暑热”。“除”在此处为“去除、清除”义，属于平声义项（《广韵》直鱼切）。仄声义项“除去、去除旧官任新官”与此处一般性“去除”有所不同。Base 和 RFT 均判断为平声。但原始标签为仄声，可能受到“除”在“除夕”、“扫除”等词中仄声习惯的影响。

---

## 案例 4：Both 真正错误

| 项目 | 内容 |
|------|------|
| **目标句** | 漪藻忘冰**候** |
| **目标字** | 候（第5字） |
| **原始标签** | 仄声 |
| **Base 预测** | 平声 |
| **RFT 预测** | 平声 |
| **DeepSeek 三次** | 仄声 / 仄声 / —（不一致） |

**分析**：“候”字在《广韵》中仅收胡遘切（去声），属仄声。平声义项一般不做常见区分。此处“冰候”指“寒冷时节”，“候”为“时节、气候”义，应读仄声。Base 和 RFT 均误判为平声，属于真正的模型错误。DeepSeek 三次结果也不一致，进一步说明此类低频用法对模型判断有挑战。

---

## 总结

- 案例 1 展示了标签质量问题的典型模式——原始标签按字音词典机械赋值，忽略了实际语境
- 案例 2 展示了多音字标注中的版本和学术歧义
- 案例 3 展示了原始标签受常见词义干扰的情况
- 案例 4 是模型真正的判断错误（低频用法 + 语义模糊）

这些案例说明：评测结果不仅反映模型性能，也受标签质量影响。对于存在争议的样本，保留原始结果并单独说明风险。
